# Roadmap — куда движется Boilergen и AI в Grand Games

> Стратегический документ. Где мы сейчас, куда движемся, и почему **Grand Games может стать первой студией, которая упростит геймдев-разработку через AI** на постсоветском рынке.

---

## Vision

**Grand Games — первая студия в регионе, которая системно использует AI как мультипликатор продуктивности команды.**

Не "AI делает игру". Не "ChatGPT для маркетинга". А **встроенные в daily-workflow** инструменты, которые:
- ускоряют разработку в 2–5×
- стандартизируют код и снижают регрессии
- освобождают программистов от рутины — для творческой работы

Boilergen — **первый камень** в этой стратегии. Не последний.

## Roadmap по фазам

### 🔴 Фаза 1 — Boilergen MVP в продакшен (3–4 недели)

**Цель:** Boilergen используется командой Игоря на реальных задачах, **измеренное** ускорение, демо директору.

**Этапы:**
1. Ответы от Игоря на бриф (1 неделя)
2. Реальные шаблоны GM1 + интеграция в репо (2 недели)
3. Замер baseline + повторный замер с Boilergen (3 дня)
4. Демо директору со слайдами "до/после" (3 дня)

**Критерий успеха:**
- Хотя бы один разработчик команды добавляет 2-3 новых сущности через инструмент
- Замеренное сокращение времени **минимум в 5×** на boilerplate-слое
- Зелёный свет от директора на следующие фазы

### 🟡 Фаза 2 — Внедрение готовых AI-инструментов (4–6 недель)

**Цель:** команда начинает использовать AI на повседневных задачах. **Не разработка** — внедрение готовых проверенных продуктов.

**Что внедряем (с обоснованием):**

#### Cursor / Claude Code (CRITICAL)
- **Кто:** 1–2 разработчика команды Игоря для пилота, потом расширение.
- **Зачем:** AI-ассистент в IDE — пишет код по описанию, объясняет существующий код, рефакторит, генерирует тесты.
- **Стоимость:** $20/мес/чел (Cursor Pro) или $20/мес (Claude Pro).
- **Ожидаемый эффект:** ускорение **на ~30% общей разработки** (не только boilerplate, а вся работа в IDE).
- **Riski:** команда может не принять "AI пишет код за меня" — нужен пилот с трекингом метрик.

#### Granola / Otter / встроенный в Mac (NICE-TO-HAVE)
- **Зачем:** автосаммари встреч → меньше "что мы решили в прошлый раз?" → быстрее онбординг.
- **Стоимость:** $0–25/мес/чел.

#### DeepL Pro / Claude API для локализации (NICE-TO-HAVE)
- **Зачем:** первый проход переводов на 10+ языков делает AI, человек правит. Сейчас, видимо, делается вручную.
- **Стоимость:** $30/мес или ~$0.0001 за слово через API.

**Критерий успеха:**
- Cursor/Claude Code пилот — измеренное ускорение
- Метрики локализации: новый язык за день вместо недели
- Никто из команды не возвращается к "чистой" работе без AI

### 🟢 Фаза 3 — Собственные AI-инструменты на Grand Games данных (2–3 месяца)

**Цель:** инструменты, которые **готовых аналогов нет** — потому что они работают на специфике GM1/GM2, не на общих задачах.

**Кандидаты (приоритезируем по результатам Фазы 2):**

#### Boilergen v2 — AI-описание сущностей
**Сейчас:** программист пишет YAML руками.
**Будет:** программист (или геймдизайнер!) пишет на русском "новая профессия — таксист, базовая ставка 500 за смену, категория транспорт" → AI генерит YAML → дальше обычный pipeline.
- **Срок:** 2-3 недели после Boilergen v1 в продакшене
- **Прорыв:** **геймдизайнеры могут сами добавлять сущности** без программиста

#### AI Code Reviewer (специализированный)
**Зачем:** автоматический ревью PR в GM1 на:
- стиль кода (по конвенциям GM1)
- regression risk (трогает ли код "опасные" зоны)
- баланс игровых констант (не сломал ли цифры экономики)
- регулярные баги (memory leaks в C++, async-проблемы в Node)

Не заменяет ревью Игоря, но **снимает 70% механических проверок**, и Игорь смотрит только содержательное.

**Срок:** 4-6 недель.

#### LiveOps Co-Pilot
**Зачем:** анализ метрик ивентов в реальном времени.
- Какой ивент даёт лучший retention?
- Что предсказывает churn?
- Какой контент-микс оптимален?

AI обучается на ваших данных, советует. Ничего не запускает сам — только инсайты.

**Срок:** 8-12 недель (нужен доступ к analytics-стэку).

#### MCP-сервер для Boilergen
**Зачем:** Cursor/Claude может вызывать Boilergen напрямую командой *"создай профессию таксиста с базовой ставкой 500"*. Без CLI, без UI — прямо в IDE.
- **Срок:** 1-2 дня (наша архитектура core+adapters готова к этому)

#### GM-Helper Bot для Discord/Telegram админов
**Зачем:** AI-ассистент для GM-команды — отвечает на типовые тикеты игроков, помогает с правилами, эскалирует только сложное.
- **Срок:** 4-6 недель.

### 🔵 Фаза 4 — Расширение по департаментам (3–6 месяцев)

**Цель:** AI-инструменты во всех функциях, не только в разработке.

**Кандидаты по департаментам:**

| Департамент | AI-инструмент | Сложность |
|---|---|---|
| **Game Design** | Генератор квестов/диалогов из синопсиса (RPG-классика) | Средняя |
| **Маркетинг** | Креативы для App Store / соцсетей по характеристикам игры | Низкая (готовые тулзы) |
| **Аналитика** | Text-to-SQL — "покажи retention за последний месяц по странам" | Средняя |
| **QA** | AI-генератор тест-сценариев из описания фичи | Высокая |
| **Саппорт** | Сентимент-анализ + категоризация тикетов | Низкая |
| **Лор/контент** | Генератор NPC, локаций, item-описаний | Средняя |

**Не делаем сами** — внедряем готовые или пилотируем (Notion AI, Jasper, Granola, ElevenLabs для голосов NPC).

### 🟣 Фаза 5 — Grand Games AI Platform (6–12 месяцев)

**Цель:** Внутренняя платформа, которая **обобщает** наши собственные инструменты.

**Что это значит:**
- Все наши custom-инструменты (Boilergen, code-reviewer, livops, etc.) — модули на одной платформе
- Единая авторизация, единый dashboard, единая аналитика
- Discoverable: новый сотрудник заходит, видит "вот инструменты, которые есть в компании"
- Метрики использования: что окупается, что нет

**Стратегический эффект:**
- В индустрии **никто этого не делает на постсоветском пространстве**.
- Мы становимся **примером** — другие студии будут копировать или приходить к нам за консультациями.
- Возможность **открыть платформу** или её часть как продукт для других студий — новый revenue stream.

## Почему мы будем первыми

### Региональный контекст

- В Казахстане/России **gamedev** — относительно молодой и небольшой
- Подавляющее большинство команд **не используют AI системно** (мы это знаем по Grand Games — те же 3 месяца на ивент)
- Crisis-driven adoption AI ожидается в индустрии **в 2026–2027**
- Кто **сейчас** перестроится — будет на год-два впереди

### Конкурентная фора

Большие западные студии (EA, Ubisoft, Riot) уже строят свои AI-стэки. Маленькие инди-студии **застряли** в копипасте. Grand Games — **средняя** — может **обогнать инди скоростью** и **обогнать гигантов гибкостью**.

### Стратегическое преимущество от Boilergen

Boilergen сам по себе — **wedge**. Он:
1. Решает реальную боль (3 месяца → меньше)
2. Имеет измеримый эффект (ROI в часах)
3. Создаёт **доверие** к AI-инициативам в команде ("работает! не страшно!")
4. Освобождает время разработчиков для следующих AI-инициатив (виртуальный круг)

Без него остальные фазы будут восприниматься как "ну ещё одна модная штука" → отвергаются → инициативы умирают.

## Ключевые риски

### 1. **Команда не примет AI**
**Митигация:** Cursor/Claude Code на 1-2 человека сначала, метрики, постепенное расширение. Никаких "всем должны использовать".

### 2. **Boilergen не приживётся**
**Митигация:** Фаза 1 строится на Игоре. Без его ревью и поддержки — действительно может умереть. Поэтому первая встреча, доступ к репо, постоянный фидбек — критичны.

### 3. **AI-инструменты дороже чем экономия**
**Митигация:** считать ROI на каждом шаге. Cursor $20/мес — окупается если экономит 1 час в месяц. Это легко.

### 4. **Утечка данных через AI-сервисы**
**Митигация:** для всех custom-инструментов — Claude API (enterprise privacy), не публичные ChatGPT. Готовые тулзы (Cursor) — pre-flight проверка договоров и data residency.

### 5. **Игорь уйдёт**
**Митигация:** документация (как этот документ), code review другого сениора, постепенный расцентрализаций знания. Минимизировать зависимость от одного человека.

## Что прошу от руководства

Не сейчас, а как фундаментальный support по мере роста:

1. **Бюджет на лицензии готовых тулзов** в Фазе 2 — порядка $300–500/мес.
2. **Время команды Игоря** — 30-60 мин ревью раз в 1-2 недели на Этапе 3, потом меньше.
3. **Полномочия** делать пилоты на 1-2 разработчиках в каждой новой фазе. **Без риска** "всем срочно перейти".
4. **Понимание что некоторые эксперименты не сработают.** Из 5 кандидатов в Фазе 3 — 2-3 отвалятся, и это нормально.

---

## Что прошу от меня (от себя самого)

1. **Не размазываться.** Закончить Фазу 1, потом думать про Фазу 2. Не пытаться делать всё сразу.
2. **Измерять.** Каждая инициатива должна иметь чёткие "до/после" цифры.
3. **Слушать команду.** Если разработчики говорят "это бесит" — не игнорировать. Инструмент должен **помогать**, не **навязываться**.
4. **Документировать.** Как этот файл — чтобы любой новый человек или стейкхолдер мог за 10 минут понять состояние и план.
5. **Не хайпить.** Это не "AI революция". Это набор практичных инструментов которые экономят время.
