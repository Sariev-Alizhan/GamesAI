# GamesAI

Internal AI tooling and automation for game development at Grand Games.

## Projects

- **[boilergen](./boilergen/)** — Code generator. Reads YAML entity descriptions and emits boilerplate code across stack layers (C++ server, Node API, Flutter admin, JSON i18n). Supports in-place file injection (Hygen-style) for registering entities in routers/indexes. ~50 tests, ESM + TypeScript.
- **[brief-igor-v2.md](./brief-igor-v2.md)** — Pending brief for the GM1 lead dev. Once answers land, Boilergen Stage 3 (real templates) starts.

Future tools (AI code-review bot, LiveOps assistant, MCP adapters, etc.) will live as sibling subfolders.
