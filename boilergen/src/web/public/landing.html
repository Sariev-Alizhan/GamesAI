The platform

Three tools. One pipeline. Zero AI lock-in.

Each module owns one boring-but-time-consuming part of game development. Composed, they form a build pipeline that takes one YAML and emits production-grade output across your entire stack.

Boilergen

YAML entity → boilerplate code across the stack. Generates C++ / Node / Flutter / Godot / Unity / Lua / i18n stubs from one schema. Five engine plugins shipped, each composable.

v 1.x tests 228 templates 51

Schema Validator

Catches broken cross-references in YAML/JSON game data and lints FiveM fxmanifest.lua graphs against case-sensitivity, missing-script, and unmanifested-dep footguns.

v 0.2.0 tests 73 modes YAML + FiveM

Localization Assistant

Static checks (placeholder parity, length overflow, per-key caps) before any AI call. Then AI fill via Claude or DeepL Pro. AI translates only what passes lint.

v 0.2.0 tests 64 providers 2
Inside the platform

A workflow built like a build system, not a chat box.

Modules read your config, talk to each other through stable contracts, and emit deterministic output. AI runs at the edges — translation, RAG-grounded suggestions, never the codegen core.

One YAML in. Nine production files out.

The codegen pipeline is content-addressable: change the YAML, only the affected files regenerate. CI runs the same pipeline. AI is opt-in for the parts that benefit from it.

  • Schema-driven entity definitions consumed by every plugin.
  • Per-engine plugins emit version-correct code (NGO 2.x, Lua 5.4, GDScript v2).
  • Validator runs as a pre-commit hook and a CI job.
  • Localization keys ride along; lint catches placeholder drift before AI fill.

End-to-end demo

From one YAML to a working FiveM/QBCore resource in 60 seconds.

Reproducible step-by-step in CASE-STUDY-PLATFORM-LOOP.md. Every command runs from a fresh clone of the public repo.

~/games-ai · zsh — generate 
1. Author taxi-driver.yaml (~25 lines)

2. $ boilergen generate ./schemas/generic-rp/taxi-driver.yaml \
                  --plugin ./plugins/generic-rp \
                  --output /tmp/demo-out

   ✓ Generated 9 files across 5 stacks:
     /tmp/demo-out/cpp-server/Jobs/JobTaxiDriver.cpp
     /tmp/demo-out/node-api/jobs/taxi-driver.controller.ts
     /tmp/demo-out/flutter-admin/jobs/taxi_driver_form.dart
     /tmp/demo-out/shared/i18n/taxi_driver.locale.json
     /tmp/demo-out/fivem-qb/jobs/taxi-driver/fxmanifest.lua
                                     /config.lua
                                     /server/main.lua
                                     /client/main.lua
                                     /migrations/001_seed.sql

3. $ schema-validator check-fivem /tmp/qb-tree
   ✓ 0 errors on Boilergen-generated resource.
     (Manifest is structured to PASS by construction.)

4. $ localization-assistant lint --source en.json --target ru.json
   ✓ No issues — placeholder parity + length budgets OK.

5. $ localization-assistant fill --provider anthropic
   ✓ 6 keys translated, <3 seconds, ~$0.02 cost.

6. Drop /tmp/demo-out/fivem-qb/jobs/taxi-driver into your server's resources/
   restart, ensure it.
   ✓ [taxi-driver] Registered job "Таксист" with 4 grade(s).

   Total time: ~40 seconds.
   Hand-rolled equivalent: 1 hour minimum.

Trust posture

Clean licenses. Auditable AI providers. No surprises.

Every runtime dependency is MIT, Apache 2.0, or BSD. Every studied source is OSI-open or developer-published. We refused leaked code (Far Cry 1) on principle. We refuse hacking requests on principle. The platform's competitive posture is license cleanliness — not a checkbox, a moat.

Currently used

Anthropic Claude API (default), DeepL Pro API (opt-in BYO-key). Both: SOC 2, no training on your prompts, commercial use OK.

Refused

NLLB-200 (CC-BY-NC), DeepL Free tier (TOS forbids similar product), Mistral Experiment / Gemini free (train on prompts), Suno/Udio (red zone), leaked AAA code (legal hazard).

On the roadmap

Local Ollama (default fallback), Groq + Cerebras free tiers (commercial OK, no training), OPUS-MT for offline, NVIDIA Audio2Face for lipsync. All license-verified.
